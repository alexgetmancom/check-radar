# План развития модуля статистики такси (Яндекс.Такси / Делимобиль)

Этот документ описывает дорожную карту для расширения возможностей отслеживания поездок, чтобы превратить простые чеки в полноценную аналитику логистики.

---

## 📅 Текущее состояние
Сейчас бот просто видит общую сумму списания за поездку (как услугу «Перевозка пассажиров») и складывает её в общую категорию «Транспорт (Такси)». Сравнение цены поездок отключено, так как стоимость поездок зависит от спроса, тарифа, чаевых и расстояния.

---

## 🚀 Предлагаемые улучшения

### 1. Интеграция с электронной почтой (Email Receipts Parser)
Яндекс.Такси всегда присылает детальные отчеты о поездках на привязанную почту владельца (в виде HTML-письма).
* **Как реализовать:**
  * Настроить фоновый коннектор к почтовому ящику по протоколу IMAP (например, Gmail API или Яндекс.Почта IMAP).
  * Фильтровать письма от `no-reply@taxi.yandex.ru` с темой «Поездка с Яндекс.Такси».
  * Парсить HTML-тело письма с помощью `BeautifulSoup` для извлечения расширенной структуры поездки.

### 2. Извлечение расширенной статистики поездки
Из электронных писем мы сможем извлекать следующие данные:
* 🛣 **Маршрут:** Точки отправления (Откуда) и прибытия (Куда).
* ⏱ **Продолжительность:** Точное время начала и окончания поездки.
* 📏 **Расстояние:** Пройденные километры (км).
* 🚗 **Класс тарифа:** Эконом, Комфорт, Комфорт+, Бизнес, Ultima.
* 💰 **Детализация стоимости:**
  * Стоимость поездки по тарифу.
  * Стоимость платного ожидания.
  * Оставленные чаевые (чтобы не путать их с основной ценой поездки).
  * Примененные скидки (Плюс, промокоды).

### 3. База данных для поездок (Схема БД)
Создать новую таблицу `taxi_trips` в SQLite для хранения логов логистики:
```sql
CREATE TABLE taxi_trips (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    receipt_key TEXT UNIQUE,
    date TEXT,
    tariff_class TEXT,
    from_address TEXT,
    to_address TEXT,
    distance_km REAL,
    duration_mins INTEGER,
    fare_cost REAL,
    tips_cost REAL,
    total_cost REAL
);
```

### 4. Аналитические отчеты в боте
Добавить команды или разделы в дашборд:
* 📈 **«Мои поездки за месяц»:**
  * Общий наезженный километраж (например, *«За июнь вы проехали 142 км в такси»*).
  * Средняя стоимость 1 км пути (отличный показатель инфляции цен на поездки).
  * Самый частый тариф и популярные адреса назначения (Дом, Работа, ТЦ).
  * Общее время, проведенное в дороге.
