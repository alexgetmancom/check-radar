# Сборщик чеков ФНС (Мои Чеки Онлайн) — Кастомный скрипт

Этот проект содержит легкий Python-скрипт, который общается напрямую с API сервиса «Мои чеки онлайн» (`lkdr.nalog.ru`) без использования сторонних тяжелых библиотек, Go, Java или Selenium. Он работает на стандартной библиотеке Python 3.

---

## 1. Как получить токены из браузера (Разовая настройка)

Поскольку ФНС использует капчу при авторизации, самый надежный и простой способ — это зайти под своим номером телефона через обычный браузер один раз и скопировать сессионные параметры.

1. Перейдите на сайт [lkdr.nalog.ru](https://lkdr.nalog.ru/) и авторизуйтесь по вашему номеру телефона `+7 (963) 962-93-92`.
2. После входа откройте инструменты разработчика (клавиша **F12** или правая кнопка мыши -> *Проверить код*).
3. Перейдите во вкладку **Application** (в Chrome/Edge) или **Хранилище/Storage** (в Firefox).
4. В левом меню раскройте пункт **Local Storage** и выберите `https://lkdr.nalog.ru`.
5. Скопируйте значения двух ключей:
   * **`deviceId`** (идентификатор устройства)
   * **`refresh_token`** (вечный токен обновления сессии)
6. Откройте локальный файл [credentials.json](file:///Users/alex/projects/me-checks/credentials.json) на Mac и вставьте скопированные значения вместо заглушек.

## 2. Перенос и запуск на VM 106

Поскольку скрипт написан на чистом Python без зависимостей, его очень просто запустить на виртуалке.

1. **Скопируйте файлы на VM 106:**
   ```bash
   ssh vm106 "mkdir -p ~/me-checks"
   rsync -avz ./ vm106:~/me-checks/
   ```

2. **Запустите скрипт на VM 106:**
   ```bash
   ssh vm106 "python3 ~/me-checks/fetcher.py"
   ```

Скрипт автоматически создаст базу данных SQLite по адресу `~/me-checks/data/receipts.db` на виртуалке, получит последние 100 чеков, скачает их детальный состав (товары, цены, количества) и сохранит все в базу.

## 3. Фоновый запуск по расписанию

Чтобы чеки скачивались автоматически каждые несколько часов, вы можете настроить стандартный планировщик `cron` на `vm106`.

1. Откройте планировщик на виртуалке:
   ```bash
   ssh vm106 "crontab -e"
   ```
2. Добавьте строку для запуска скрипта каждые 6 часов (например, в 00:00, 06:00, 12:00, 18:00):
   ```text
   0 */6 * * * python3 /home/alex/me-checks/fetcher.py >> /home/alex/me-checks/fetcher.log 2>&1
   ```
